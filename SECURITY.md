# Politique de sécurité

## Signaler une vulnérabilité

N'ouvre pas d'issue publique pour une vulnérabilité exploitable.

Utilise de préférence la fonctionnalité de signalement privé de sécurité de GitHub lorsqu'elle est disponible, ou contacte directement le mainteneur du dépôt.

Merci d'inclure :

- la version concernée ;
- la plateforme ;
- les étapes de reproduction ;
- l'impact potentiel ;
- une proposition de correction, si disponible.

## Périmètre

Le projet interagit avec des sites tiers et peut dépendre de leur comportement, de leurs cookies, de leurs API et de leurs protections. Un dysfonctionnement lié à un site tiers n'est pas nécessairement une vulnérabilité de HakuNeko Next.

## Builds

Télécharge les versions depuis la section Releases officielle du dépôt. Les builds non officielles ne sont pas garanties.
