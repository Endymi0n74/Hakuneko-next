# Vibe coding et développement assisté par IA

## Définition utilisée dans ce projet

Ici, le terme **vibe coding** désigne une méthode de développement dans laquelle des assistants IA participent activement à l'exploration, à l'écriture, au refactoring, au débogage et à la documentation.

Cela ne signifie pas que les résultats sont acceptés sans contrôle.

## Outils utilisés

- ChatGPT / OpenAI
- Codex
- GitHub Copilot
- Visual Studio Code
- Git et GitHub
- GitHub Actions

## Processus de validation

Une modification suit idéalement ce parcours :

1. formulation du besoin ;
2. génération ou modification assistée du code ;
3. lecture du diff ;
4. compilation locale ;
5. lancement de l'application ;
6. test de la fonction concernée ;
7. analyse des logs ;
8. correction ;
9. validation dans GitHub Actions ;
10. publication d'une release testable.

## Transparence

Le dépôt indique volontairement que l'IA est utilisée. L'objectif est d'être clair sur la méthode de développement, sans présenter les assistants IA comme une garantie de qualité.

La qualité dépend des tests, de la compréhension du changement et de la validation réelle du résultat.
