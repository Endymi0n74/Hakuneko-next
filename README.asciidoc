# ✨ Features

## 📚 Download

- Manga

---

## 🔍 Search

Search supported sources instantly.

---

## 🔄 Automatic Chapter Tracking

Unlike a simple downloader, HakuNeko Next can automatically:

- refresh chapter lists
- detect newly released chapters
- update your library
- notify pending downloads (future)

---

## ⏰ Scheduled Monitoring

Monitor your favorite series automatically.

Configure the checking interval and let HakuNeko Next periodically verify whether new chapters are available.

No more manual refreshing.

# 🛠 Development

Requirements

- Node.js 22+
- npm

Install

```bash
npm run npm:clean-install
```

Development

```bash
npm --workspace=web run serve:dev
npm --workspace=app/electron run launch:dev
```

Desktop build

```bash
npm --workspace=app/electron run bundle
```

This project embraces an AI-assisted development workflow.
