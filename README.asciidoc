# À propos

**HakuNeko Next** est un fork du projet **HakuNeko**.

Ce fork n'a pas pour vocation de remplacer le projet d'origine, mais de poursuivre son évolution en expérimentant de nouvelles fonctionnalités, en améliorant le packaging desktop et en automatisant la publication des builds.

Un immense merci aux développeurs et contributeurs du projet original, sans lesquels ce fork n'existerait pas.

---

# Pourquoi ce fork ?

L'objectif est de proposer une version plus orientée **desktop** avec notamment :

- 🖥️ une application Electron autonome ;
- 📦 des releases générées automatiquement ;
- 🔄 le chargement automatique des chapitres ;
- 👀 la surveillance automatique des nouveaux chapitres ;
- ⏱️ des vérifications périodiques configurables ;
- ⚡ une chaîne de build modernisée ;
- 🛠️ des améliorations progressives de l'expérience utilisateur.

## 👀 Surveillance des séries

Une série peut être surveillée automatiquement.

À intervalle régulier, HakuNeko Next vérifie :

- si de nouveaux chapitres sont disponibles ;
- si la liste doit être actualisée ;
- si des téléchargements peuvent être lancés.

Fini les vérifications manuelles répétitives.

# Installation

Téléchargez la dernière version depuis **Releases**.

Aucune installation n'est nécessaire.

---

# Développement

Installation :

```bash
npm run npm:clean-install
```

Développement :

```bash
npm --workspace=web run serve:dev

npm --workspace=app/electron run launch:dev
```

Build :

```bash
npm --workspace=app/electron run bundle
```

---

# Développement assisté par IA

Ce projet est développé selon une approche de **développement assisté par intelligence artificielle**.

Des outils comme **ChatGPT**, **Codex** et **GitHub Copilot** sont utilisés pour accélérer :

- le développement ;
- le refactoring ;
- le débogage ;
- la documentation ;
- le packaging.

Chaque modification est ensuite :

- relue ;
- compilée ;
- testée localement ;
- validée dans GitHub Actions ;
- vérifiée sur une véritable build desktop avant publication.

L'objectif est d'accélérer le développement tout en conservant une validation humaine.
