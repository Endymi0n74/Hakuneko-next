# Code de conduite

Ce projet souhaite maintenir un espace accueillant, respectueux et constructif.

## Comportements attendus

- Rester courtois, même en cas de désaccord.
- Critiquer le code ou les idées, jamais les personnes.
- Donner des retours précis et utiles.
- Respecter les niveaux d'expérience différents.
- Signaler les problèmes de manière responsable.

## Comportements inacceptables

- Harcèlement, insultes ou intimidation.
- Discrimination.
- Publication d'informations privées.
- Spam ou perturbation volontaire des discussions.

Les responsables du projet peuvent masquer, supprimer ou fermer les contributions qui ne respectent pas ces règles.
